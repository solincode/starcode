StarsCode

Plataforma interactiva para dominar Data Science a través del análisis de datasets estelares. Aprende a procesar, visualizar y entender el universo con código.

Lleva la teoría a la práctica. Utiliza las reglas de temperatura estelar para clasificar el dataset: desde las ardientes estrellas Clase O hasta las frías Clase M. Filtra los resultados, valida las etiquetas y crea tu propio dataset personalizado en formato CSV, estarás clasificando estrellas sacadas del catálogo GAIA.

Explora el cielo como un laboratorio de datos. Visualiza estrellas del catálogo Gaia sobre un mapa astronómico interactivo, selecciona objetos en el campo estelar y analiza sus propiedades físicas mediante código. Observa posiciones, colores, magnitudes y distancias para interpretar el universo desde los datos.

Programa en Python directamente sobre nuestro dataset estelar. Utiliza la terminal integrada para realizar la limpieza de valores nulos, clasificar datos masivos y personalizar la estética de tus gráficas. Procesa variables físicas en tiempo real para generar tu propio Diagrama HR.
