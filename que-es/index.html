Dataset

Este módulo permite construir un conjunto de datos estelar a partir de reglas de clasificación astronómica. Las y los usuarios pueden trabajar con información de estrellas, aplicar criterios basados en temperatura y color, filtrar resultados y validar etiquetas.

StarsLab

StarsLab permite explorar estrellas del catálogo Gaia sobre un mapa astronómico interactivo. Las y los usuarios pueden observar el cielo, seleccionar estrellas directamente desde el campo estelar y revisar sus propiedades físicas, como posición, color, magnitud, temperatura y distancia.

StarsCode Notebook

StarsCode Notebook permite programar directamente sobre un dataset estelar utilizando Python. Las y los usuarios pueden limpiar datos, trabajar con variables físicas, generar gráficos y construir visualizaciones como el Diagrama HR.

Aprendizaje guiado

StarsCode está diseñado para ser utilizado junto a clases y actividades pedagógicas. Cada módulo funciona como una herramienta práctica que acompaña la explicación teórica

permitiendo que las y los participantes apliquen conceptos de astronomía, ciencia de datos y programación de forma interactiva.
